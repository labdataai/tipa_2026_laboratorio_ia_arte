# Recursos

## Datos abiertos

- [datos.gob.ar](https://datos.gob.ar): datos abiertos del Estado nacional.
- [data.buenosaires.gob.ar](https://data.buenosaires.gob.ar): datos abiertos de la Ciudad de Buenos Aires.
- [kaggle.com/datasets](https://www.kaggle.com/datasets): datasets de todo tipo, con ejemplos de código.
- [The Library of Missing Datasets](https://github.com/MimiOnuoha/missing-datasets), Mimi Ọnụọha (2016): los datos que nadie recolecta.

## Herramientas

- [editor.p5js.org](https://editor.p5js.org): editor web de p5.js, sin instalación.
- [docs.ml5js.org](https://docs.ml5js.org): documentación de ml5 (bodyPose, handPose, faceMesh, imageClassifier).
- [huggingface.co/spaces](https://huggingface.co/spaces): modelos para probar en el navegador.
- [Diffusion Explainer](https://poloclub.github.io/diffusion-explainer/): cómo funciona la difusión, paso a paso.
